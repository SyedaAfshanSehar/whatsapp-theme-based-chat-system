WhatsApp Theme-Based Chat System

A fully functional real-time chat application built with Python, Socket Programming, and Tkinter GUI designed to simulate a WhatsApp-like messaging experience over a local network.

Features

Real-time messaging using Socket Programming
Multi-client support
WhatsApp-style chat bubbles (green/white)
Timestamp on every message
Join notifications
Server-side GUI with Tkinter
Scrollable chat window
Send message with Enter key or Send button

Tech Stack

Language: Python
Networking: Socket Programming
GUI: Tkinter
Threading: Python Threading Module

How to Run

1. Clone the repository: git clone https://github.com/SyedaAfshanSehar/whatsapp-theme-based-chat-system
2. Run the server: python server.py
3. Enter your server name when prompted
4. Run the client: python client.py
5. Enter your name and start chatting!

 How It Works

The server starts and listens for connections. The client connects and enters a name. A join notification is sent to all users. Real-time messages are broadcast to everyone instantly.
